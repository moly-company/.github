# moly-company/.github

GitHub's organization defaults: the issue and pull-request templates every moly-company
repository uses unless it has its own. Public, as GitHub requires; templates only.

Where the rest lives: the project board <https://github.com/orgs/moly-company/projects/1>,
shared CI in [moly-company/ci](https://github.com/moly-company/ci), and the Claude Code
plugins in [moly-company/claude-plugins](https://github.com/moly-company/claude-plugins).
